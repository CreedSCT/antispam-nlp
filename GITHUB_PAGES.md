# Публикация GitHub Pages

Аккаунт: CreedSCT. Предлагаемое имя репозитория: antispam-nlp.

1. Создать публичный репозиторий antispam-nlp.
2. Загрузить содержимое этой папки в корень репозитория, сохранив папку docs.
3. Settings → Pages → Source: Deploy from a branch.
4. Branch: main, Folder: /docs, Save.
5. Дождаться успешной публикации. Ожидаемый URL: https://creedsct.github.io/antispam-nlp/

Адрес выше пока предполагаемый. Проверить фактическую публикацию в Settings → Pages.
GitHub Pages запускает браузерную модель из docs. Python FastAPI и Dockerfile хранятся в репозитории, но сервер на Pages не запускается.
