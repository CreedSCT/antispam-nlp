## Фактическое состояние

- Обучающие источники: SpamAssassin + LingSpam bare.
- 6125 писем после удаления 1306 совпадений с тестом и 161 внутреннего повтора.
- Train 4900, validation 1225. Seed=42. TF-IDF униграммы/биграммы внутри Pipeline.
- Сравнивались ComplementNB и LogisticRegression, 5-fold CV.
- Выбрана ComplementNB, threshold=0.57, по максимуму F1 при FPR <= 1% на validation.
- В тесте преподавателя 1600 файлов, 1598 непустых. Из них 600 ham, 998 spam, 1543 уникальных текста.
- Итог: Precision 0.993435, Recall 0.909820, F1 0.949791, TN=594 FP=6 FN=90 TP=908.
- FastAPI /predict, /health, /docs. Dockerfile готов, сборка Docker не проверена.
- Публичная браузерная публикация модели: https://antispam-nlp-study.swoonyjoy17.chatgpt.site
- Паритет браузерной модели и Python: 0 расхождений меток на 1598 письмах, max error 7.34e-14.
- Дополнительный классификатор категорий: реклама, работа, знакомства, мошенничество, обычное. Учился на 40 искусственных фразах / 160 вариантах. Macro-F1 GroupKFold 0.580, реальная категорийная проверка отсутствует.
