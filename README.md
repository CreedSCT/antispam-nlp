# Антиспам NLP: итоговое задание

## Что готово

- Два обучающих корпуса: SpamAssassin и LingSpam (bare).
- MIME/HTML обработка, исключение вложений, дедупликация и контроль совпадений с тестом.
- Сравнение ComplementNB и LogisticRegression с 5-fold CV.
- Выбор порога только на валидации с ограничением FPR <= 1%.
- Готовая модель, предсказания теста, численные отчёты.
- FastAPI с /predict, /health, /docs, Dockerfile.
- Публичное браузерное демо: https://antispam-nlp-study.swoonyjoy17.chatgpt.site
- Экспериментальная дополнительная модель категорий.

## Реальные результаты

После очистки: 6125 писем, обучение 4900, валидация 1225.
Удалено 1306 совпадений с тестом и 161 повторов внутри обучения.
Тест: 1600 файлов, 1598 непустых (600 ham, 998 spam), 1543 уникальных нормализованных текста. Два письма с пустым текстом исключены, метрики относятся к остальным 1598.

Выбрана ComplementNB, порог 0.57. Precision 0.993435, Recall 0.909820, F1 0.949791, FPR 0.010000.
TN=594, FP=6, FN=90, TP=908.

## Быстрый запуск на Windows (PowerShell, Python 3.12)

Распаковать ZIP и открыть PowerShell в папке `antispam`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000 и http://127.0.0.1:8000/docs.
Модель уже обучена. Повторное обучение для демонстрации не нужно.

## Воспроизведение эксперимента

Сырые письма специально не включены в ZIP. Они могут содержать опасные ссылки или вложения. Код читает их как данные, не открывает URL и не исполняет вложения. Не отключать антивирус.

```powershell
.\.venv\Scripts\python.exe download_data.py
.\.venv\Scripts\python.exe train.py --test C:\путь\test_task_emails.tar.xz
.\.venv\Scripts\python.exe train_categories.py
.\.venv\Scripts\python.exe -m unittest test_project -v
```

`train.py` пишет artifacts/model.joblib, reports/metrics.json и reports/test_predictions.csv. Векторизация выполняется заново на каждом фолде CV. Финальная модель сохраняется без переобучения после выбора порога. Источники и SHA256 находятся в metrics.json и download_data.py.
`train_categories.py` также обновляет JSON в папке `site_source`. Для обновления основной модели в браузере запустить `python export_browser.py` после обучения.
Для интерактивного разбора использовать `Антиспам_эксперимент.ipynb`.

## Веб-демо

В браузер экспортированы словарь, IDF и веса уже обученной модели. Текст остаётся в браузере. На 1598 тестовых письмах результат совпал с Python по всем меткам, максимальная ошибка оценки 7.34e-14.
Это публикация модели в браузере, а не публикация FastAPI-контейнера. Серверный вариант входит в проект как отдельный способ запуска.
В `site_source` находится копия исходников браузерного демо без служебных учётных данных.

## Дополнительная модель категорий

TF-IDF + LogisticRegression, 5 категорий: реклама, работа, знакомства, мошенничество, обычная переписка.
Обучающий набор искусственный: 40 базовых фраз, 160 вариантов. GroupKFold не разделяет варианты одной исходной фразы между обучением и проверкой.
Macro-F1 на таком наборе: 0.580. Это слабый прототип, его качество на реальной почте не подтверждено. Категорийных меток в тесте преподавателя нет. Не обещать максимальную оценку за эту часть.

## Ограничения и использование ИИ

Исторические обучающие корпуса в основном англоязычные. Внешний тест содержит также другие языки. Отдельные языковые метрики не рассчитывались. Близкие дубликаты и общие источники могут остаться после исключения точных совпадений. Современная почта и реальные категории требуют отдельной проверки.
Например, в ложные срабатывания попали уведомления образовательных сервисов и лицензий. Среди пропусков есть короткий случайный текст, обфускация и русскоязычная рассылка. Это наблюдения по отдельным примерам, не доказательство причин для всех ошибок.
Оценка predict_proba не проходила отдельную калибровку. Модель не заменяет антивирус.

ИИ использовался при подготовке кода, экспериментов и материалов. По условиям курса автор должен понять, проверить и доработать результат и самостоятельно сформулировать ключевые выводы. В `ЗАЩИТА.md` есть объяснения и вопросы для подготовки.
